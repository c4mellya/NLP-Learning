# 实验任务要求

课程：大模型与自然语言处理，第 2 次实验。
主题：用 Agent 制作 LMAPI 知识网页。
选题：C — Prompt Caching / Prefix，为什么前缀稳定能省钱。

## 学习目标

理解稳定前缀与 KV 复用的关系，比较 OpenAI 与 Anthropic 的 API 形式，通过“探索 → 规格化 → 迭代”练习给 Agent 写清晰的行为规格。

## 交付内容

- 单页知识网页：围绕一个核心概念，包含稳定前缀命中、修改字符后失效的动态交互，引用官方资料。
- `AGENTS.md`：以 Task / Constraints / Data / Output 分开指令与数据，明确受众、范围和交付形式。
- Prompt 日志：至少两轮，包含原始 Prompt、输出问题、规格修改、效果变化和结论。
- 源码反思：阅读 Hermes agent/prompt_builder.py，对照 Prompt 组装机制解释迭代中的问题。
- 公网网页与课程在线文档：使用个人独立项目发布，并提交页面及过程材料。
