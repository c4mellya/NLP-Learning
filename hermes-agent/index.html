安装方式、常见错误与验收

macOS / Windows 可选图形安装；Linux、macOS、WSL2、Termux 可用 Shell 脚本。执行在线安装脚本前先阅读官方说明。代码目录与用户数据目录 ~/.hermes/ 的职责不同。

# macOS / Linux / WSL2 / Termux：
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
# Windows PowerShell（二选一，不要混用）：
irm https://hermes-agent.nousresearch.com/install.ps1 | iex

按当前 Shell 重新载入配置，例如 source ~/.bashrc 或 source ~/.zshrc，也可直接重开终端。

现象检查与处理
command not found检查 command -v hermes 与 echo $PATH；Windows 用 Get-Command hermes 和 $env:PATH。
缺少 API Key运行 hermes model 完成认证；只在 Secret 存储录入凭据。
配置缺失先运行 hermes doctor，按提示补齐，再执行 hermes config check。

验收 命令可执行、交互界面可启动、doctor 可诊断；能说明安装入口与用户目录的用途。

Provider 选择与验收

可用 Nous Portal、OpenRouter、Anthropic、DeepSeek 或本地服务。具体模型、认证与功能以服务商文档为准。

学习工具调用时建议选择上下文至少 64K token 的模型。对话、工具定义与结果都占上下文。本地推理需配置上下文，例如 llama.cpp 的 --ctx-size 65536。

验收 配置正确的 Provider / Model，在同一会话中完成至少两轮对话；用 hermes -c 恢复会话。

  • 认证失败：检查 Provider、Key / OAuth 状态和 Secret 存储位置，不打印凭据。
  • 模型不存在：核对模型标识与 Provider 实际开放的模型。
  • 接口或网络错误：检查 Base URL 路径、API mode 与目标服务是否兼容。

验收 解释五个配置的职责；安全配置提供的 API，明确指定 Provider / Model 后得到验证回复。

启动方式、快捷键与验收 
hermes                           # 交互入口
hermes --tui                     # TUI 入口
hermes chat -q "请概括当前任务"    # 单次问题
hermes sessions list             # 已保存会话
hermes --continue                # 恢复最近会话
hermes --resume <session-id>      # 恢复指定会话

Enter 发送；Ctrl + G 调用外部编辑器；Ctrl + D 退出；Unix 下 Ctrl + Z 挂起。

命名用 /title 我的项目；其他会话命令见 hermes sessions --help。中断后检查会话状态。

验收 能解释 Provider / Model、工具摘要、token 使用和压缩状态；完成多行输入、中断和恢复。

打开一个文件，辨认哪些内容可以分享，哪些绝不能公开。

  backend: local

服务商、模型、端点、协议、终端后端。

仅显示教学占位符。

配置覆盖顺序

  1. CLI 参数单次覆盖
  2. config.yaml普通配置
  3. .env环境变量 / Secret
  4. 内置默认值未设置时回退

从左到右，优先级由高到低。.env 不公开分享。

配置命令与验收 
hermes config
hermes config edit
hermes config set model.default <model-id>
hermes config set terminal.backend docker
hermes config check

普通配置可引用环境变量，如 api_key: ${PROVIDER_API_KEY}。

  • 普通配置：Provider、Model、Base URL、终端后端、工具选项。
  • Secret：API Key、Token、OAuth 凭据。不进入公开仓库、截图或日志。
  • 检查 Git 忽略规则，泄露后轮换凭据。

验收 说明四个核心文件与优先级；修改非敏感值并检查配置，不展示 Secret。

Bash 中用 cat summary.md 复核。网页只演示过程，真实文件需要在你自己的运行环境中生成。
